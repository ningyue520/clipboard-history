# 历史粘贴板

历史粘贴板是一款 Windows 桌面剪贴板管理工具。它会自动记录复制的文字和图片，帮助你随时找回、整理、搜索和重新复制剪贴板内容。所有数据只保存在本机，不上传云端。

## 软件亮点

- **自动记录**：监控剪贴板变化，自动保存文字、图片和截图。
- **快速复制**：双击任意历史卡片即可复制完整内容，回到目标应用直接粘贴。
- **收藏整理**：重要内容可加入收藏，支持“全部 / 文本 / 图片”筛选。
- **自定义备注**：收藏条目可添加最多 60 字的备注，便于标记用途或来源。
- **图片预览**：图片条目支持独立大图预览、滚轮缩放、拖拽平移和 ESC 关闭。
- **图片搜索**：图片内容会尝试进行本地 OCR 识别，识别结果可用于搜索。
- **历史分组**：按日期展示历史记录；超过保留期限的内容会进入“已过期”区，可手动清空。
- **静默启动**：可选择开机后仅在托盘运行，不自动弹出主窗口。
- **窗口锁定**：标题栏可锁定窗口位置，同时不影响搜索、复制、收藏等功能。
- **自定义快捷键**：支持单键或组合键呼出，可用 Backspace 或 Delete 清空后重新录制。

## 适用场景

- 需要反复复制、粘贴常用文字或链接。
- 想找回刚才复制过但已被覆盖的内容。
- 需要整理常用片段、参考资料或截图。
- 希望剪贴板记录只保存在本地，不依赖云同步。

## 安装与使用

1. 运行 Windows 安装包，例如 `历史粘贴板 Setup 1.2.0.exe`。
2. 安装后从桌面或开始菜单打开“历史粘贴板”。
3. 正常复制内容，软件会自动记录到历史列表。
4. 双击卡片复制内容，或在右上角使用星标收藏、删除。
5. 在“设置”中调整保留期限、开机启动、关闭行为、快捷键和使用说明。

## 数据与隐私

- 所有历史记录、图片、备注和设置都保存在本机。
- 不包含账号登录、云同步、遥测或广告。
- 图片 OCR 识别在本机进行，识别文本仅用于本地搜索。
- 数据目录：`%APPDATA%\历史粘贴板`。

## 开发

本项目使用 Electron、原生 HTML/CSS/JS 和 Tesseract OCR。

```bash
npm install
npm start
```

语法检查：

```bash
node --check main.js
node --check preload.js
node --check renderer/app.js
node --check renderer/preview.js
```

打包：

```bash
npm run dist
```
